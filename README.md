# Customer Segmentation & Churn Pattern Analytics in European Banking

## Overview

This project analyzes customer churn patterns in a European banking dataset using Microsoft Power BI. The dashboard helps identify high-risk customer segments based on geography, age, gender, account balance, and customer engagement.

## Objectives

- Analyze customer churn patterns
- Identify high-risk customer segments
- Compare churn across geography, gender, age, and balance
- Develop an interactive Power BI dashboard
- Provide business recommendations to improve customer retention

## Tools Used

- Microsoft Power BI
- DAX
- CSV Dataset
- Microsoft Excel

## Project Files

- Research Paper.pptx
- project-1.pbix
- European_Bank.csv
- Dashboard Screenshots

## Key Findings

- Overall Churn Rate: **20.37%**
- High Value Churn Ratio: **25.23%**
- Geographic Risk Index: **32.44%**
- Engagement Drop Indicator: **26.85%**
- Germany recorded the highest customer churn.
- Customers aged **46–60** showed the highest churn.
- High-balance customers exhibited higher churn than other balance groups.

## Business Recommendations

- Improve customer engagement for inactive customers.
- Develop personalized retention strategies for high-value customers.
- Increase cross-selling opportunities.
- Monitor customer churn continuously using Power BI dashboards.
